# Local data

`places.jsonl` contains 500 historical place metadata records reused from RoamWise. The app searches Cambridge only.

`checked_places.json` contains dated official facts for five Cambridge museums. Its 30-day planning window is a project policy. It is not a live availability feed.

See [sources](../docs/SOURCES.md) for origins, links and limits. Review texts, reviewer profiles and credentials are not included.
